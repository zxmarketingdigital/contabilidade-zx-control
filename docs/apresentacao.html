// O que é este setup

Um produto pronto que você revende — não um código pra escrever

A lógica dos 5 agentes é congelada e validada (suíte de testes verde). Sua instalação aqui no Claude Code só configura o produto para o escritório cliente: credenciais, banco, deploy e validação. Nada de programar.

📦 Núcleo congelado

Mesma engenharia dos demais pacotes da linha. Versionado por tag vX.Y.Z — você nunca toca em src/.

⌨️ Texto → texto, sem upload

Nenhum agente lê PDF, XML ou extrato. O contador digita ou cola; a IA nunca emite número extraído de arquivo — na contabilidade um valor mal lido vira lançamento errado.

🔐 Roda na infra do cliente

Supabase + Cloudflare por escritório (free tier dá conta). Login multiusuário: cada pessoa do escritório tem o seu acesso, dados compartilhados, RLS em toda tabela.

💸 Você instala e cobra

White-label. Acompanha uma masterclass de como vender e precificar para contadores e escritórios contábeis pequenos.

// O motor

Os 5 agentes

Todos texto→texto. Toda saída de IA traz o disclaimer obrigatório "conferência pelo contador é obrigatória" e nunca afirma valor de imposto, alíquota ou número de lei — orientação genérica, conferência com o profissional.

texto → texto

Dados da empresa em texto → ficha, regime sugerido (Simples / Presumido / Real), obrigações, documentos a pedir e parecer preliminar.

Pergunta do contador → orientação fundamentada e genérica, sempre com remissão à legislação vigente.

texto → texto

Redator de Respostas ao Fisco

Intimação/notificação colada como texto → minuta de resposta estruturada, exportável.

// O que destrava o valor

O que ensinar ao cliente

⚠️ Como o escritório tira o máximo

  • Cadastrar a carteira de empresas — com regime correto, o Agente 1 monta a agenda certa de cada cliente.
  • Conferir toda saída de IA — o disclaimer não é decoração: a responsabilidade técnica é sempre do contador.
  • Marcar prazos como cumpridos — mantém a agenda limpa e o destaque de vencidos/≤5 dias confiável.

💸 Como você ganha: ancore o preço nas horas que o escritório economiza por mês — poucas horas de trabalho manual já pagam o sistema. Prefira setup maior + mensalidade baixa pra reduzir churn.
